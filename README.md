# Flat Top, Barrel & Grill

Blackstone griddle, Pit Barrel Cooker and grill recipes: beef and chicken mains, sides and appetizers. Filter by cooker, type, region and time. Meal Nights, an "I don't know" wheel, and a grocery list you can share to Google Keep.

Live: https://rsissons.github.io/grill-recipes/

Recipes are condensed and adapted from the credited sources. Each recipe links to its original.

## Adding a recipe

Click **+ Add a recipe** on the site (or open a new issue with the *Add a recipe* form) and paste a link. A GitHub Action reads the recipe data the page embeds, sorts it by cooker, type and region, adds it to `added.js`, and replies on the issue. Only the repo owner's submissions are processed.
